## 阅读与演示

- 老五新增P1三条简单并行轴：开剑组、Boss杀机、引导刃轮，共用同一时间刻度；开剑排班、走位与转P时点明确为示例。
- 默认进入“团员省流版”：一句站位、阶段流程和每技能一句操作；职责筛选继续可用。
- 每个首领可切回“完整攻略”，记住阅读偏好；技能动图直接显示，支持播放、逐步查看和放大；整场演示按需展开，收起即停止播放。
- 每位首领包含阶段主线、开场站位与分组、职责筛选、技能速查和整场动画。
- 44项技能都可播放处理流程；支持暂停、逐步查看、重播与放大。
- 每位首领新增可展开的“正式服技能轴”，标明开战、血线、技能事件和机制完成的计时起点；顶部“技能轴”可直接展开定位。
- 整场演示仍使用教学血线和速度，可跳阶段、拖动、倍速；真实参考计时看独立技能轴。
- 老五保留三种配平案例，实时展示25人赤幽人数、层数抵消、隔绝与清色。配平按带色人数，不按层数总和。
- 手机适配、全团打印、离线直接打开均可用，无外部脚本依赖。

## 本次正式服修订

- 老一：60%阶段后续接原轮次；跳波推荐W＋一次一段跳仍落同棺，水墙在扶摇最高点接轻功。
- 老二：半场/电扫配双黄，四红配单黄；每次按实际点名核人数。枪兵改看路径覆盖区域，修正P1与P2组合顺序。
- 老三：缩短火环段并补随机脚下散雷；寂夜最低后散雷次数增加，停逐猎与新火环，收尾技能加速。
- 老四：开场染魂与后续固定轴独立于鸟死亡；邪气2/3/5/5。第三轮以完整消圈作为主线，投弹时序与鸟盾同步。补穿透伤害、阴性伤害和浮游天地豁免。聚邪帮手站残圈外、承伤范围内；黄泉斩稳定在20尺外可不动。
- 老五：每把在2.5尺内互动，每次8秒，任意2次成功生效；各组3人可同时读条增加容错，不等第三人。幽影按实际注视处理，三刀约隔1.5秒；保留选人与落圈结束提示的资料差异说明。补T跨轮赤煞交接、接圈上限与隔绝仍计人数。

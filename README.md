# 洛阳之战 · 首领机制手册

《剑网3》苍生铸世50级新赛季，**25人普通测试服**五首领技能识别、应对与分工。

在线阅读：<https://wohehuoguo.github.io/jx3-luoyang-guide/>

资料整理日：2026-10-22。以10月中下旬公开技能资料和实战攻略为主，正式服更新后需要重新核对。

作者：坐下来谈谈不@梦江南 with codex

## 使用

- 直接打开 `index.html`，全部样式、图示与脚本均已内嵌，可离线使用。
- 老一至老五均有阶段主线、开场站位图和精简开怪清单；团长详细分组与替补表默认折叠，打印时完整展示。
- 职责筛选置于首领标题下并随滚动保留，可直接跳到技能速查。
- 全部44项技能都有4–7步流程动画：预警或点名、走位或处理、结算、归位；纯团伤演示治疗覆盖和血线恢复。默认暂停，可播放/暂停、上一步/下一步、直接选步骤与重播。
- 俯视图沿用开场朝向；侧视、转阶段和人数示意单独标注，说明临时换位与处理后的归位。
- 涉及点名与面向的技能标注跟随、锁向和结算规则；老三逐猎演示前段随目标转向、读条过半锁向后侧躲。资料未明确的锁定时机单独注明。
- 每张技能图的“放大演示”同样支持播放；一次只播放一段，切换首领或职责会停止旧动画。教学节奏不对应实战秒数，打印版保留静态图。
- 44项机制逐条配有原创站位图、侧视跳跃图或机制流程图；图示不按实际坐标或比例绘制。
- 按首领导航；按坦克、治疗、输出筛选实际需要主动处理的技能，按钮显示当前职责的技能数。
- 坦克专属点名仅归坦克，不因普通治疗照看而同时归入治疗；单纯承受AOE不算额外输出职责。
- 筛选后显示对应职责的具体动作。搬弹、开剑、引导等任务按常用分工归类并显示任务组说明；其他心法兼任时切换到“全团”。
- 使用搜索框查技能或处理关键词，按 `/` 聚焦搜索，按 `Escape` 清除。
- 勾选“只看处理”用于快速复习。
- 老五附戾煞人数配平演练；保留机制所需次数与人数，不收录伤害、血量和配装要求。
- 老五另有P1开剑／引导出入圈流程、P2赤煞／幽煞来源表；对应技能直接标注颜色与层数，并区分幽影斩的红色预警和实际幽煞效果。
- 打印按钮可打印全部首领或保存为 PDF，手机和电脑均可阅读。
